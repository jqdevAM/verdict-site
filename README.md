# verdict-site

The public pages for the Verdict Android app.

| Page | URL |
|---|---|
| Home | https://jqdevam.github.io/verdict-site/ |
| Privacy policy | https://jqdevam.github.io/verdict-site/privacy/ |

Published with GitHub Pages: Settings → Pages → Deploy from a branch →
`main`, folder `/` (root).

The pages are the copies kept in the app's own repository, at `site/`.
**Change them there and copy them here**, so the policy and the behaviour it
describes stay together — every sentence in it is a claim about what the app
reads from Google, what it keeps, and what it changes. Google's OAuth review
reads this policy too, against the scopes the app asks for.
